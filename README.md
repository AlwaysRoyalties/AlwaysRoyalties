# AlwaysRoyalties

A beta script mod for The Sims 4. It runs the game’s existing royalty payments for authors in all played households, including households that are not currently active.

## Download and install

Download [AlwaysRoyalties.ts4script](AlwaysRoyalties.ts4script) or the [v0.1.0-beta package](AlwaysRoyalties_v0.1.0-beta.zip). Place the `.ts4script` file in `Documents/Electronic Arts/The Sims 4/Mods` (directly or one folder deep). Enable Script Mods in Game Options > Other, then restart the game.

Royalties advance while the save is open and Sim time advances. They do not accumulate while the game is closed.

## Compatibility and testing

Tested in one live save on The Sims 4 build 1.127.41.1030: an inactive played household received payments on two consecutive in-game days. Other game versions, royalty categories, saves, and mod combinations have not been independently tested.
