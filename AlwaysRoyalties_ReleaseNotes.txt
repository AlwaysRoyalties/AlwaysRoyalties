Always Royalties v0.1.0 beta

Summary
An invisible script mod that advances vanilla royalties for Sims in all played
households on the game's daily royalty alarm, even when another household is
active.

Initial test
Tested in one live save on game build 1.127.41.1030. The inactive author's
household received royalties on two consecutive in-game days.

Known scope
- Uses the game's shared royalty tracker and tuned payment logic.
- No progress occurs while the game is closed.
- This beta has only been checked in one save and has not been independently
  validated for every royalty category or mod combination.
