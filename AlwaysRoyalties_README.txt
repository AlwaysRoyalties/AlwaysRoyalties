Always Royalties — v0.1.0 beta

WHAT IT DOES
Pays existing vanilla royalties to Sims in all played households when the
game's daily royalty alarm runs, including households that are not active.
It uses the game's royalty tracker, curves, multipliers, and payment variation.
It adds no menus and suppresses royalty notifications for inactive households.

INSTALLATION
1. Copy AlwaysRoyalties.ts4script into Documents/Electronic Arts/The Sims 4/Mods
   or one folder inside Mods.
2. In Game Options > Other, enable Script Mods if needed.
3. Restart the game and load the save.

WHEN PAYMENTS RUN
The mod uses the game's existing daily royalty alarm. Payments happen while a
save is open and Sim time advances. No payments accumulate while the game is
closed. Funds go to the author's household.

TEST STATUS
Initial live-save check on The Sims 4 build 1.127.41.1030: a Sim's inactive
household received royalties on two consecutive in-game days. The amounts
varied, as expected from the game's payment deviation. This is a beta test in
one save; broader compatibility and individual royalty categories have not
been independently tested.

UNINSTALLATION
Remove AlwaysRoyalties.ts4script from Mods. The mod stores no separate history
or settings.
